# 客户端请求头透传

## 背景

new-api 转发上游时是**新建**一个 `http.Request`，只写入白名单请求头：

- `SetupApiRequestHeader`：Content-Type、Accept、User-Agent
- 各 adaptor：如 Claude 的 `x-api-key`、`anthropic-version`、`anthropic-beta`
- 渠道 `header_override`

客户端其余请求头（`x-app`、`x-stainless-*`、各类客户端归属头等）**全部丢弃**。`pass_through_body_enabled` 只透传请求体，管不到请求头。

部分上游会校验客户端身份头（例：aihubx 网关对 Claude Code 请求要求 `x-app: cli` 及客户端归属头，缺失时返回 400 `code 400002` / `phase R-1`），这类渠道必须开启请求头透传才能正常使用。

## 用法

在渠道的**请求头覆盖**（`header_override`）里配置，JSON 对象。

### 透传规则（键为规则，值忽略，留空即可）

| 键 | 含义 |
|---|---|
| `"*"` | 透传全部客户端请求头 |
| `"re:<正则>"` / `"regex:<正则>"` | 透传名字匹配该 Go 正则的请求头 |

正则同时按规范名（`X-App`）和全小写名（`x-app`）匹配，两种写法都行，不必写 `(?i)`。

### 变量占位符

| 占位符 | 含义 |
|---|---|
| `{api_key}` | 渠道 API Key |
| `{client_header:<头名>}` | 取客户端同名请求头的值；客户端没传则该头不写入 |

`{client_header:...}` 必须是整个值，不能和其它文本拼接。其取到的是客户端可控内容，不会再做 `{api_key}` 插值。

### 示例

透传 Claude Code 客户端身份头：

```json
{
  "re:^x-": "",
  "X-App": "{client_header:x-app}",
  "Authorization": "Bearer {api_key}"
}
```

全量透传：

```json
{
  "*": ""
}
```

## 约束

- **凭证头不透传**：`authorization`、`api-key`（Azure）、`x-api-key`（Claude）、`x-goog-api-key`（Gemini/PaLM）不会被 `*` / 正则规则带到上游，否则客户端可用同名头顶掉渠道密钥。需要时用显式覆盖单独指定。
- **WebSocket 鉴权头不透传**：`sec-websocket-protocol` 在 OpenAI Realtime 里承载 `openai-insecure-api-key.<渠道密钥>`，透传会顶掉鉴权子协议导致握手失败；`sec-websocket-key` / `-version` / `-extensions` 由 dialer 生成。
- **逐跳头不透传**：`connection`、`proxy-connection`、`keep-alive`、`proxy-authenticate`、`proxy-authorization`、`te`、`trailer`、`transfer-encoding`、`upgrade`，外加 `host`、`content-length`、`accept-encoding`、`cookie`。
  另外会解析 `Connection` / `Proxy-Connection` 里**动态声明**的字段名（RFC 7230 §6.1）并一并剥掉，防止客户端用 `Connection: X-Hop` 把任意字段标成逐跳后仍送达上游。
- **显式覆盖优先**：透传先应用，普通覆盖后应用，同名以覆盖为准。
- **显式空值有意义**：`{"Authorization": ""}` 会把 adaptor 设置的凭证覆盖成空值（历史行为）。只有 `{client_header:...}` 取不到客户端头时才跳过不写。
- 覆盖 `Host` 时会同步写 `req.Host`，否则不生效。

## 生效范围

| 场景 | 静态覆盖 / `{api_key}` | 透传规则 / `{client_header:}` |
|---|---|---|
| 普通转发（`DoApiRequest` / `DoFormRequest` / `DoWssRequest`） | ✅ | ✅ |
| 任务渠道（Suno / Jimeng / Doubao / Gemini 等，`DoTaskApiRequest`） | ✅ | ✅ |
| 渠道测试 | ✅ | ⛔ 无真实客户端请求 |
| 拉取上游模型列表 | ✅ | ⛔ 无真实客户端请求 |

无真实客户端请求的带外调用（`c` 为 nil 或渠道测试）不会报错，只是自动跳过透传与 `{client_header:...}`。
